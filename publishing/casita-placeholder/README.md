# Casita name reservation

This `0.0.0-placeholder` package reserves the crates.io name for
[Casita](https://github.com/cachix/casita), an actively developed verified
object repository. It does not contain the Casita library or command-line tool.
Do not depend on or install this placeholder for application use.

The current source and installation instructions are in the
[Casita repository](https://github.com/cachix/casita). To install the CLI from
Git while a crates.io release is being prepared, run:

```sh
cargo install --git https://github.com/cachix/casita casita --locked
```

The first functional crates.io release will use a later version of this same
package name.

wait and a 180-second retry failed before the benchmark process was launched.
The [raw report](2026-09-11-tar-quiet.json) retains both failed attempts, exact
options/binary fingerprints, and the retry's process-activity samples.

The retry recorded 166 intervals. Every interval observed competing compiler
or benchmark processes: `cargo`, `.cargo-wrapped`, `rustc`, `rust-lld`, `cc1`,
and/or `casita-lib-test`. External CPU utilization across all logical CPUs
had a median of 45.43% and maximum of 91.96%. The admission policy requires
ten quiet seconds, no recognized competing build/benchmark processes, and
at most 5% sampled external CPU utilization. No existing process was stopped.

This is an unavailable timing comparison, not a regression or a zero-cost
measurement. The earlier shared-host timing report remains inconclusive.
The committed-repository hash histograms are independent of timing and
passed all payload correctness gates.

## Permanent runner

`benchmarks/tar_compare.py` runs the permanent `tar_import` matrix four times,
alternating concurrency order 1/16 and 16/1. It builds nothing during
measurement, checks binary SHA-256 before and after each matrix, creates fresh
Criterion directories, preserves raw samples and estimates, requires all
16 cases, and records waiting as well as measurement activity. Each timed
import retains the existing canonical-root, published-root, counts, logical
bytes, and full-readback checks. Contended results and admission failures
are retained and cause a nonzero exit.

The cases remain registered in `benchmarks/manifest.json` and included in
`benchmark all`. The repeated/guarded runner is also documented in the case
registry. Three runner tests cover incomplete/duplicate case rejection,
alternating order with retained contended data, and admission failure with
its activity evidence. Both tar orders passed all 16 cases in correctness-only
mode. All-features/all-targets Clippy and the 20 benchmark-harness tests passed.

```sh
devenv shell cargo bench --features experimental --bench tar_import --no-run
python3 -m benchmarks.tar_compare \
  --binary /path/from/cargo/tar_import-BUILD_ID \
  --output /tmp/tar-paired-new --repetitions 4 --quiet-timeout 180
```

Run this command on a quiet Linux host. Sampling quietness still does not
prove physical isolation; retain the environment and per-run controls before
making a throughput claim. The available SSH host was macOS, while this
runner's existing activity guard requires Linux `/proc`.
